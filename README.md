# IBM 6540 Final Report: Online Shoppers

This repository contains the Group 6 final project for IBM 6540. The project uses the UCI Online Shoppers Purchasing Intention dataset to predict whether a website session will end in a purchase and to identify useful behavioral and audience patterns.
